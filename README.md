## Verification

The deployed application has been tested for:

* Room creation and joining from separate browsers or devices.
* YouTube video playback.
* Synchronized play, pause, and seek controls.
* Host permissions and participant management.

## Current Limitations

* Room and playback state are stored in server memory, so a backend restart clears active rooms.
* Persistent room history and database storage are not implemented.
* Availability depends on the hosting services and network connectivity.
